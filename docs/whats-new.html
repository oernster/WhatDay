Changelog

What's new

Recent releases have focused on saying exactly what WhatDay does: one update check, disclosed down to the headers its request carries; an uninstall that really removes the program folder; the decisions behind it written down. Earlier ones added Yellow to the palette and made starting at sign-in your choice.

v1.3.0

What the update check sends, stated exactly

  • The update check's request carries only the standard headers Go adds to any request: an Accept header, Go's default user agent and a request for a compressed answer. The README, the specification and the site now say exactly that; there is still no version, no identifier and no telemetry in it
  • Uninstall could leave the program folder behind when setup was still open on its last screen. Setup now waits until it has actually closed, then removes the folder, trying again a few times if a file is still held for a moment
  • A new document, DECISIONS-TRADEOFFS.md, sets out each deliberate choice WhatDay rests on and what it costs, checked against the code as it stands
  • The documents now mention that setup can start WhatDay as soon as it finishes; they describe the build, the log and the strip's height on a monitor with no taskbar as the code has them
v1.2.0

WhatDay tells you when there is a new version

  • A few seconds after it starts, then once a day, WhatDay asks GitHub whether a newer release has been published. Download opens the new setup program in your browser; Skip This Version never offers that version again; Later asks at the next check
  • The tray menu gains Check for updates, just below About. It always answers: with the offer, with word that you have the latest version or with a message saying GitHub could not be reached
  • The update check is WhatDay's one network connection: an anonymous read of its own public releases list. A test fails the build if any other code tries to reach the network; the setup program still connects to nothing
  • The site now lives at ernster.dev/WhatDay. One download button always fetches the newest setup program; the spacing between sections is back
v1.1.0

Yellow joins the palette

  • The tray menu offers seven colours rather than six. Yellow sits between Amber and Green, kept clearly apart from Amber on the taskbar; the colour you already chose is unchanged
  • WhatDay's one-line description, shown by setup and at the head of this site, now asks what bloody day it is rather than using the stronger word it used to carry
v1.0.1

Starting at sign-in is your choice

  • Setup's install, update and repair screens carry Start WhatDay when I sign in to Windows. It is ticked on a fresh install; on the repair screen a change takes effect at once
  • Setup now writes its sign-in entry and its Apps list commands with each path plainly in quotes instead of with every backslash doubled. Running this version's setup once rewrites all three
v1.0.0

The first release: what day is it?

  • The name of the day in a small, borderless, always-on-top strip just above the Windows 11 taskbar, as tall as the taskbar. It has no taskbar button and no Alt+Tab entry; it hides while a fullscreen application is open
  • The day follows the timezone Windows is set to and changes at local midnight. It catches up after sleep, a clock change or a timezone change
  • Drag the strip wherever you like and it remembers its place. Six colours are in the tray menu
  • A setup program installs WhatDay for your account only, with no administrator rights. Uninstalling removes everything WhatDay wrote
  • No network connection of any kind; a test fails the build if its code imports a network package
